Fabric Cleaner · UnoRouter

Turns a photo of quilted or printed fabric into a clean, flat print: weave texture and quilting stitches removed, design kept. This version sends requests to an OpenAI-compatible /chat/completions endpoint. Make quilt mockups · Clean a whole folder at once · Open the original version

Output

Click “Load model list” to fetch the model ids your key can use, then pick one that generates images.
The size is worked out for each image with the same limits as gpt-image-2.5-sunburst: up to 3840px on the long side and about 8.3 megapixels in total (e.g. 2880 × 2880 for a square), keeping the photo's shape. It's sent as the size field (e.g. "size": "2880x2880") and also written into the instructions. Each version is billed. Planning effort is OpenAI's complexity field (how much the model plans the picture before drawing it, separate from Quality); it isn't sent on the chat endpoint.
Added to every request body, and can override the fields above, e.g. {"output_format": "png"}.
